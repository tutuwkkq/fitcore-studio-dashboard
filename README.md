# Studio FitCore - Sistema de Acompanhamento 🏋️‍♂️

## 1. Briefing do Problema
O FitCore cresceu de 15 para 80 alunos ativos. O processo manual com fichas de papel e PDFs no WhatsApp se tornou um caos, tomando horas dos 3 personal trainers e causando o esquecimento dos treinos pelos alunos em dias sem acompanhamento[cite: 1]. Isso ameaçava a retenção exigida pela investidora anjo[cite: 1].

## 2. Decisão de Design e Solução
A solução foi um **Dashboard (para professores) + App (para alunos)**. A plataforma elimina o papel, permite aos professores prescreverem treinos rapidamente e dá aos alunos acesso aos vídeos de execução e registro de cargas, fortalecendo o vínculo e a retenção[cite: 1].

## 4. Arquitetura Utilizada

## 5. Instruções de Execução
Para testar a aplicação localmente:
1. Faça o clone do repositório[cite: 2].
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox) ou utilize a extensão "Live Server" no VS Code[cite: 2].
